## 📌 Executive Overview

This repository hosts the official personal web portfolio of **Grandhisila Preethi Ahalya**. Designed at the convergence of **Modern Design Aesthetics, Game Developer Audio-Visual Dynamics, and Full Stack Software Architecture**, this application presents a single-page interactive 3D platform demonstrating technical proficiency, production systems, and academic accomplishments.

### 🎯 Key Engineering Highlights
* **Zero Dependency Overhead:** Built as a 100% self-contained single-file architecture (`index.html`) optimized for instant loading, zero build-step maintenance, and global edge delivery via GitHub Pages.
* **Spatial 3D Canvas:** Powered by **Three.js WebGL**, rendering an interactive 1,800-particle starfield galaxy with real-time mouse parallax, inertia smoothing, dynamic orbital rings, and click shockwave impulses.
* **Synthesizer Sound Architecture:** Employs the native **HTML5 Web Audio API** to generate real-time synthesized acoustic UI cues (sine sweeps, frequency ramps, harmonic chords) with zero external media files.
* **Live In-Browser Game Demonstration:** Integrates an interactive live widget of the **Typewriter** typing speed engine directly on the page, computing real-time Words Per Minute (WPM), accuracy percentages, and persisting personal best scores via `localStorage`.
* **Developer CLI Emulator:** A built-in retro-futuristic interactive terminal drawer (hotkey: `` ` `` / `~`) offering interactive commands for inspecting technical competencies, certifications, and architecture details.

## 💻 Local Setup & Execution

Because the entire application is contained within a clean, single-entry architecture, no local compilation or package installations are strictly required.

### 1. Clone the Repository
```bash
git clone https://github.com/preethigrandhisila/portfolio.git
cd portfolio
```

### 2. Launch in Browser
You can launch `index.html` directly in any modern web browser:

* **Direct Open:**
  * Double-click `index.html`, or right-click and choose **Open with Google Chrome / Edge / Firefox / Brave**.
* **Via Python HTTP Server:**
  ```bash
  python -m http.server 8000
  ```
  Navigate to `http://localhost:8000` in your web browser.
* **Via Node `npx serve`:**
  ```bash
  npx serve .
  ```

## 🌐 GitHub Pages Deployment Guide

To enable live hosting on GitHub Pages:

1. Navigate to the repository settings on GitHub:
   `https://github.com/preethigrandhisila/portfolio/settings/pages`
2. Under the **Build and deployment** section:
   * **Source:** Select `Deploy from a branch`.
   * **Branch:** Select `main` (or `master`) and specify `/ (root)`.
3. Click **Save**.
4. GitHub Pages will build and deploy the application. Your live site will be accessible at:
   ```
   https://preethigrandhisila.github.io/portfolio/
   ```
